# SPEC 004 — Investments

## INV-001
Import current positions available from Pluggy/Nubank.

## INV-002
Import investment transactions when available.

## INV-003
Patrimônio screen shows:
- investment total;
- basic allocation by type;
- contributions this month;
- net-worth composition.

## INV-004
Market value and contributed capital must not be conflated.

## INV-005
Investment gains must not be counted as new owner contribution.

## INV-006
If provider investment data is unavailable/stale, UI shall show last sync/reference date rather than fabricate current value.
