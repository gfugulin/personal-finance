# SPEC 001 — Mobile Shell

## UI-001
The product shall expose exactly four primary mobile navigation destinations:
Hoje, Movimentações, Patrimônio, IR.

Acceptance:
- bottom nav visible on mobile app pages;
- active tab obvious;
- Settings not a fifth primary tab.

## UI-002
The default route after authentication shall be Hoje.

## UI-003
All critical tasks must be usable at 360px CSS viewport width.

## UI-004
Primary KPI screens shall avoid horizontal scrolling.

## UI-005
App shall be installable as PWA.

## UI-006
Plain-language Portuguese shall be used for primary UI copy.
