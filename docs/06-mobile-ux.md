# Mobile-First UX

## Principle

One-thumb, low-cognitive-load interface.

No desktop-first tables in primary flows.

## Primary navigation

Bottom nav, exactly four items:

1. Hoje
2. Movimentações
3. Patrimônio
4. IR

## Hoje

Priority order:

1. Dinheiro livre
2. Cash / card commitment
3. Month income / spend / invested
4. Monthly saving/investment target
5. net-worth trend
6. tax YTD summary
7. recent transactions

Avoid more than 2 charts on this screen.

## Movimentações

Transaction row:
- description;
- amount;
- category;
- date;
- review indicator.

Tap opens bottom sheet:
- financial classification;
- fiscal classification;
- category;
- source account;
- installment if available;
- create "always classify" rule.

## Patrimônio

- total net worth;
- cash;
- investments;
- card liability;
- allocation;
- simple historical line chart;
- contributions this month.

## IR

Year selector.

Cards:
- taxable YTD;
- exempt/non-taxable;
- exclusive/definitive;
- tax withheld/paid;
- estimated tax;
- pending reviews.

Sections:
- annual dossier;
- deductions;
- year-end position;
- checklist.

## Language

Use plain Portuguese.

Prefer:
- "Entrou"
- "Gastou"
- "Investiu"
- "Dinheiro livre"
- "Precisa revisar"

Avoid exposing domain jargon unless needed.
